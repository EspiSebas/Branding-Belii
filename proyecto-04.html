Proyecto 04

Identidad de marca

Una identidad visual que transforma la esencia de Belii en un sistema gráfico reconocible, versátil y coherente en sus diferentes aplicaciones

El proyecto

Identidad de marca

El reto. Construir una identidad visual para Belii que representara su propósito: transformar ideas en marcas con personalidad, capaces de conectar con las personas. El desafío era desarrollar un sistema gráfico reconocible, flexible y coherente en diferentes aplicaciones.

La idea. Crear un universo visual a partir de un logosímbolo propio, acompañado de recursos gráficos, tipografías y una paleta cromática que transmitieran creatividad, cercanía y dinamismo. La propuesta se extendió a diferentes aplicaciones para explorar cómo la identidad podía adaptarse a distintos formatos sin perder su esencia.

El resultado. Un sistema de identidad visual acompañado de un manual de marca y aplicaciones gráficas que establecen los criterios para utilizar la marca de manera consistente. El proyecto reúne elementos digitales y físicos que permiten reconocer a Belii y expresar visualmente su personalidad.
